# Legacy Artifacts Policy

This repository retains original R-based coursework artifacts for reference, but they are not part
of the active refresh pipeline.

Legacy files:

- `DallasArrests.Rmd`
- `DallasArrests.pdf`
- `DallasArrests_cleaned.csv`
- `Dallas_Arrests_Property_Summary.csv`
- `Police_Arrests.csv`
- `Zillow-dallas.csv`

Policy:

- Do not treat legacy files as active data or executable entry points.
- Do not modify legacy files as part of routine Python refresh work.
- Use Python CLI workflow (`acquire`, `build`, `analyze`) for all ongoing updates.
